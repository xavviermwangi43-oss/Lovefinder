# Love Finder

A starter Android app built with Python + Kivy + Buildozer.

## Build on GitHub

1. Create a new GitHub repository.
2. Upload all files in this folder, including `.github/workflows/build-apk.yml`.
3. Open the repository's **Actions** tab.
4. Run **Build Love Finder APK**.
5. When the workflow finishes, open the workflow run and download the **LoveFinder-APK** artifact.

## Important

This starter APK is the Android/Kivy front end. It is intentionally separate from the Flask server you were running in Termux. Real multi-user chat, authentication, photo storage, and payments need a backend/service connection before they can work between different phones.
